# Supports de présentation — LogX AI

Matériel pour présenter LogX AI (identité graphite & cuivre, message « l'IA prépare,
l'opérateur déclenche »). Contenu strictement factuel — ne présenter que ce que l'app fait.

| Fichier | Quoi | Usage |
|---|---|---|
| `logx_presentation_radioamateurs.html` | Présentation web #1 — public **radioamateurs** | Ouvrir dans un navigateur, projeter/partager. Thème jour/nuit (bouton haut-droite). |
| `logx_presentation_grand_public.html` | Présentation web #2 — **grand public / institutionnel** | idem |
| `logx_presentation_technique.html` | Présentation web #3 — **technique / dev** | idem |
| `logx_decks_claude_design.md` | Plans de decks (3 publics) | À coller dans **Claude Design** pour générer des slides/PPTX : coller la « Direction artistique » puis le bloc PROMPT du deck voulu. |
| `logx_video_script_13min.md` | Script vidéo ≈ 13 min (voix off + « à l'écran ») | Pour **enregistrer une vidéo** (capture d'écran + narration) ou dériver des slides narrées. |

Les 3 présentations web ont aussi été publiées comme Artifacts (liens privés, partageables
depuis la page). Les fichiers HTML ici en sont la source, réutilisable/modifiable hors-ligne.
