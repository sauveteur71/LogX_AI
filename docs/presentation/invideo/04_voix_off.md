# Voix off — deux options

Le texte à dire est dans `02_script_narration.md`. Deux façons de le sonoriser.

## Option A — Voix IA d'InVideo (rapide)

- Dans InVideo, choisis une **voix française**. Teste-en 2 ou 3 : privilégie une
  voix **posée, grave, naturelle** (éviter les voix trop « lecture de robot »).
- Vérifie la **prononciation des sigles** : CW, SSB, FT8, RR73, DXCC, POTA, SOTA,
  IOTA, PTT, LoTW, QSO. Si InVideo les épelle mal, deux solutions :
  - écrire la version phonétique dans le script (ex. « erre-erre-73 », « dé-ix-cé-cé »),
  - ou garder l'option B (ta voix) pour ces passages.
- Règle le **débit** légèrement lent, et ajoute des respirations entre les sections.

## Option B — Ta propre voix (recommandé pour une démo technique)

C'est la plus crédible : un opérateur qui parle de son logiciel. Procédure :

1. Dans InVideo, **désactive la voix off automatique**. Génère seulement les
   **visuels + le montage + les sous-titres** à partir du script.
2. Enregistre ta voix par-dessus, en lisant `02_script_narration.md` :
   - micro proche, pièce calme, débit tranquille, sourire dans la voix ;
   - une prise par section (INTRODUCTION, LE PROBLÈME, LA SOLUTION, DÉMONSTRATION,
     CONCLUSION) — plus simple à refaire qu'une prise unique de 10 min ;
   - laisse 1 s de silence au début/fin de chaque prise (marges de montage).
3. Cale l'audio sur les visuels dans InVideo (ou dans un logiciel de montage :
   Audacity pour nettoyer la voix, puis import).
4. Garde une **musique de fond discrète** (−18 à −24 dB sous la voix).

## Direction de jeu (les deux options)

- **Ton** : chaleureux, expert, direct. Fier sans esbroufe.
- **Insister** (légère emphase) sur : « l'IA prépare, l'opérateur déclenche »,
  « techniquement, pas seulement par principe », « le dernier mot ».
- **Ralentir** sur les passages sécurité d'émission et architecture (les plus denses).
- Phrase finale « L'IA prépare. L'opérateur déclenche. » : nette, détachée, sur le logo.
